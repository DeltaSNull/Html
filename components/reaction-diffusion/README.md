# Reaction Diffusion

A Gray-Scott reaction-diffusion simulation morphing between coral, spots, and maze patterns on a 128×128 grid, rendered in a teal-to-bone ramp on near-black — move the pointer to seed fresh chemical. Canvas 2D, zero dependencies, light-theme ready.
