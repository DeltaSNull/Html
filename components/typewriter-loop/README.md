# Typewriter Loop

A monospace terminal line that types, pauses, and deletes phrases in a loop behind a glowing green blinking block caret, with randomized keystroke timing. Zero dependencies.

![Typewriter Loop](preview.jpg)

**Open it:** [`index.html`](index.html) runs straight from disk — one file, every asset inlined, no build step.
